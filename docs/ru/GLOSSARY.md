# Термины перевода

Выборы для трёх переводов этой версии. *(inferred)* Сопоставлены с
[глоссарием](../01-overview/glossary.md): используются нейтральные термины вместо поисковых
разговорных вариантов («корпа», «квар», «крафт»). *(file)* Этот глоссарий —
список поисковых синонимов, а не подтверждение официальной локализации.
Уверенность в точных названиях элементов интерфейса ограничена; спорные
варианты стоит сверять с игровым интерфейсом. ⚠ unverified

код и английские диагностические сообщения не локализуются. *(inferred)*
