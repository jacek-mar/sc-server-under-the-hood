# Cvar names in the binaries vs. the shipped configuration (generated)

> Generated by the maintainers' tooling (strings only; read-only). Companion of [binary-capability-sheets.md](../08-reverse-engineering/binary-capability-sheets.md) (per-executable lists), [engine-cvars.md](engine-cvars.md) (runtime dump of the cloud services) and [cvar-reference.md](cvar-reference.md) (settings assigned in Lua). Do not edit by hand.

## 1. Totals

* Distinct cvar-like names in 22 executables: **4238** (`DedicatedServer.exe` 3576, `game.exe` 3677).
* Names assigned by the shipped configuration (Lua + `*.cfg` + `cloud.xml`): **257**; of these **257** occur as a string in at least one binary (raw byte search, so short or unusual prefixes are included) and **0** do not.
* Names that appear **only** in `DedicatedServer.exe`/`game.exe` (battle/client layer; not in the SSH dump of the cloud services): **3459**.

Top prefixes: `sv_` 225, `ship_` 101, `cl_` 93, `spell_` 93, `mm_` 89, `max_` 80, `cam_` 71, `ai_` 60, `cheat_` 45, `shield_` 41, `dbg_` 40, `boost_` 38, `spawn_` 37, `sp_` 35, `is_` 34, `net_` 33, `mp_` 30, `aura_` 27.
